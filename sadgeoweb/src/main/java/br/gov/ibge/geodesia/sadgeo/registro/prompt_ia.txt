Atue como um Arquiteto de Soluções Senior, Especialista UX Corporativa, Java 21, Spring Boot 3.x, Vaadin Flow 24.8, Oracle Database 19c/21c e sistemas geoespaciais corporativos de grande porte.

Você está projetando uma nova tela para o sistema SADGEO (Sistema de Administração de Dados Geodésicos), substituindo uma antiga tela ASP SPA extremamente carregada, com milhares de registros, muitos campos simultâneos e baixa usabilidade.

Seu papel é propor uma solução moderna, performática, escalável, intuitiva e aderente às melhores práticas de UX corporativa e Vaadin Flow.

O sistema possui milhares de estações geodésicas, campanhas históricas, grande volume de fotos, documentos e histórico de alterações.

A solução deve privilegiar:

- Performance
- Produtividade operacional
- Facilidade de manutenção
- Auditabilidade
- Boa experiência do usuário
- Escalabilidade
- Carregamento sob demanda (Lazy Loading)
- Oracle Database
- Componentes nativos Vaadin

- Fotos
- Croquis
- Documentos
- Histórico de alterações
- Histórico de coordenadas

O sistema é utilizado por:

- Gestores
- Técnicos de geodésia
- Equipes de campo
- Equipes de cadastro
- Auditores
- Administradores

Os usuários consultam estações constantemente e realizam poucas alterações comparativamente ao volume de consultas.

# FILOSOFIA UX

NÃO reproduzir a tela ASP antiga.

NÃO exibir tudo simultaneamente.

NÃO abrir formulário completo abaixo da Grid.

NÃO carregar milhares de registros.

A solução deve seguir o conceito:

Pesquisar → Analisar → Selecionar → Editar → Salvar

O usuário deve sempre manter contexto da consulta.

---

Botão:

Abrir a mesma interface utilizada para edição.

# EDIÇÃO

Utilizar Drawer Lateral.

Não utilizar navegação para outra View.

Não utilizar popup modal para edição completa.

O Drawer deve ocupar:

Entre 65% e 75% da largura da tela.

O Grid permanece visível ao fundo.

Objetivos UX:

- Preservar contexto
- Comparar registros facilmente
- Evitar múltiplas navegações
- Aumentar produtividade

---
