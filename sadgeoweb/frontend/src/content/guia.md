# Guia de Uso e Evolução

SADGEO — Sistematização e Análise de Dados Geodésicos

## Versão 0.2

- Dashboard público com indicadores, gráficos e tabelas de consulta.
- Fatos do Painel consultados por página, com filtros e pesquisa no servidor.
- Crítica de Dados e Análise compartilham o template de registros.
- Campanha e tabelas básicas têm manutenção para usuários autorizados.
- Telas de importação, homologação e carga BDG estão preparadas para evolução; seus comandos definitivos permanecem desabilitados.

## Evolução

Os critérios e dependências das próximas entregas estão no TODO.md do repositório. Demonstração e testes locais não comprovam integração com Oracle, AD, GED ou BDG institucionais.

## Operação e acesso

Os indicadores do Dashboard são públicos. Registros operacionais e cadastros exigem login. Em demonstração, os dados são fictícios e as alterações de cadastros existem somente em memória.
